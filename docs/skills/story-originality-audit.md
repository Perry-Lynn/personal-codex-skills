# story-originality-audit

`story-originality-audit` 审查稿件与已知参考来源之间的文字、场景、结构和生成机制距离，适用于原创自查、同人转原创、授权改编和参考驱动写作。

## 审查层次

- 文字：连续重合、罕见措辞、特殊比喻和相同错误。
- 场景：目标、道具、动作、揭示和结果的低概率同序组合。
- 结构：人物功能、关系映射、转折、牺牲、奖励和结局机制。
- 来源：授权、公共领域、引用、署名和创作记录。

## 触发示例

```text
比较这份稿件和三份参考材料，做发布前原创性审计。

这篇同人想转原创，哪些地方仍是换皮的一一映射？

检查拆文后写的新稿有没有过度依赖原作，只报告不要改。
```

## 文本重合工具

```bash
python3 skills/writing/originality/story-originality-audit/scripts/text_overlap.py manuscript.md sources/ --ngram 16
```

工具只比较用户提供来源中的规范化字符片段，结果是人工审计候选。零结果不代表绝对原创，相似度也不能直接替代法律判断。

返回码为 `0`（比较完成，无论是否有候选）或 `2`（稿件/来源路径、扩展名、空目录、空白输入、读取错误、`--ngram < 8`、`--limit <= 0`、文本短于 n-gram 或没有可比较材料）。

与 oh-story-claudecode 配合时，应从 scan/analyze 阶段登记来源，在 write 阶段形成独立故事核，成稿后再审计；需要重构时交回写作 skill。
