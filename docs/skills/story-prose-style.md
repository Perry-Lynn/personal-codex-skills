# story-prose-style

`story-prose-style` 是一个项目专属网文文风 skill，用来提取、保存、应用和审查作品的正文声音。它关注“这本书应该怎么说话”，不会用一套通用模板覆盖不同题材和人物。

## 适用场景

- 从已定稿章节中提取叙述风格、对白习惯和角色声纹。
- 为新书建立 `设定/文风.md` 与 `设定/正文文风指纹.md`。
- 续写或重写前加载项目文风约束。
- 比较目标章节和稳定样本，定位文风漂移。
- 修复对白不像真人、叙述翻译腔、模板动作、空洞升华等问题。
- 在不改变剧情事实的前提下做局部文风回炉。

它不负责设计整本书的剧情，也不会在仅要求审查时自动续写、修改大纲或推进追踪文件。

## 触发示例

```text
按我的文风重写这一段，对白要像中国人正常说话。

从第 1、3、7 章提取稳定文风，建立这本书的文风文件。

检查第 26 章有没有文风漂移，只报告，不修改。

比较样章和新章的角色声纹，指出谁说话串味了。
```

## 工作模式

1. **建立文风**：从用户要求、稳定正文和对标样本提炼可执行规则。
2. **应用文风**：在写作前加载项目文风，对正文生成施加明确约束。
3. **文风校准**：比较目标章节与样本，输出 BREAK、DRIFT、TUNE 证据。
4. **维护指纹**：稳定样本增加后更新描述性指标，避免被偶然章节带偏。
5. **局部回炉**：只修用户指定的声音问题，并保留剧情事实和人物目的。

## 判定维度

- 叙述声音：视角、距离、措辞、信息密度和文学性来源。
- 对白声音：人物身份、关系、目的、口头习惯和打断方式。
- 句段节奏：句长、段落长度、手机阅读节奏和场景速度。
- 描写方式：动作、物件、环境与感官是否服务剧情。
- 情绪与幽默：情绪如何结算，笑点是否从人物和处境中生长。
- 禁止漂移：作者总结、翻译腔、模板微动作、排比答案和预告式升华。

## 文风指纹脚本

脚本依赖 Python 3，仅使用标准库。

分析一个文件或目录：

```bash
python3 skills/writing/prose-style/story-prose-style/scripts/style_fingerprint.py <target-file-or-directory>
```

将目标章节与稳定样本比较：

```bash
python3 skills/writing/prose-style/story-prose-style/scripts/style_fingerprint.py --baseline <sample-path> <target-path>
```

需要机器可读结果时添加 `--json`。脚本统计句长、段落、对白、标点和高频模板风险，只用于发现偏移，不能单独判定文风好坏。

## 主要文件

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 核心流程、优先级和交付要求 |
| `references/prose-principles.md` | 对白、叙述、节奏、爽点和去模板化原则 |
| `references/style-artifacts.md` | 项目文风文件和正文指纹的结构 |
| `references/style-review-rubric.md` | BREAK、DRIFT、TUNE 审查标准 |
| `references/story-router-integration.md` | 与其他 story skills 的配合边界 |
| `scripts/style_fingerprint.py` | 文风指标提取和基线比较工具 |

## 输出边界

审查报告应写清检查范围、采用的文风权威文件、样本、核心结论、证据、已修改内容和待作者确认的边界。量化指标是漂移信号，不是写作配额。任何改变事实、伏笔、人物状态或章节承接的修改，都应交回相应写作流程处理。
