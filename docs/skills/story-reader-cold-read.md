# story-reader-cold-read

`story-reader-cold-read` 用受控的两遍阅读复原真实读者体验。第一遍严格不看大纲、设定、追踪表和旧审稿结论，只记录正文让读者知道什么、误解什么、期待什么以及何处想跳读或弃读；第二遍才与作者意图对照。

## 适用场景

- 检查开篇或章节哪里看不懂、哪里会弃读。
- 验证信息差、悬念、伏笔和误导是否被普通读者接住。
- 找到最强翻页点、最大阅读阻力和未结算的期待债务。
- 区分“作者脑中成立”和“正文已经写出来”。

## 触发示例

```text
不看大纲，先按第一次读到这里的读者视角审这一章。

告诉我哪里会回读、跳读或弃书，先不要改正文。

完成盲读后再对照细纲，看哪些信息只存在于作者脑中。
```

## 两遍协议

第一遍只读公开材料，并建立读者已知、推测、疑问、情绪、阻力和动力账本。第二遍再读取作者资料，将偏差分为正文缺失、投放早晚、信号强弱、有益误导和破坏性误导。

它不是全能审稿：结构、逻辑、人物和连续性仍交给 `story-review`；剧情修改交给 `story-long-write` 或 `story-short-write`。

| 文件 | 用途 |

| `SKILL.md` | 两遍盲读流程、边界和交付要求 |
