# story-originality-audit：小说原创性审计

审查作品与已知参考材料之间的“表达和组合距离”。不凭空宣布绝对原创，也不提供规避查重或掩盖抄袭的方法。默认只报告，不自动改稿。

## 建立审计范围

1. 锁定待审稿件版本、章节范围和用途：原创、授权改编、同人、公共领域改编或内部练习。
2. 建立来源清单：用户提供的原作、对标、素材、研究笔记、生成过程和授权信息。
3. 将来源分为已提供全文、只有书目信息、未知潜在来源。结论只覆盖实际比较过的材料。
4. 对真实人物、新闻、案件和他人隐私另行标记事实来源与伦理风险。
5. 未经用户授权，不向外部服务上传未公开稿件或受版权保护的完整参考文本。

来源登记模板和风险分级见 `references/originality-rubric.md`。

## 执行四层比较

### 1. 文字层

查找连续或近连续重合、罕见措辞、特殊比喻、对白节奏和错误也一致的片段。可运行 `scripts/text_overlap.py` 生成候选，但候选必须人工复核。

### 2. 场景层

比较场景目标、进入方式、关键道具、冲突动作、信息揭示和退出结果是否以相同组合与顺序出现。单一通用桥段不构成高风险，多个低概率细节同序组合需要重点审查。

### 3. 结构层

比较主要情节节点、反转时点、人物功能、关系映射、死亡或奖励顺序、世界规则和结局机制。不能只通过改名、换职业、换性别掩盖一一映射。

### 4. 来源与变换层

核对稿件新增了什么独立选择、因果、主题、人物欲望和表达，而不只是表面替换。授权、公共领域或同人身份会影响发布方式，但不会自动消除署名、许可和平台规则要求。

## 分级

- `COMMON`：题材惯例、公共事实、常见表达或不可垄断的抽象点子。
- `DISTINCT`：存在相似起点，但人物选择、因果链、场景组合和表达已形成独立作品。
- `DEPENDENT`：多个具体元素仍依赖同一来源，需要重构或明确改编身份。
- `HIGH_RISK`：出现较长文字重合、罕见细节同序、结构一一映射或明显来源遮蔽。
- `UNKNOWN`：缺少来源全文、授权或创作记录，无法判断。

这是一项编辑与来源审计，不是法律鉴定。高风险商业发布或争议稿件应交由合格专业人士复核。

## 修订方向

优先改变作品的生成机制：人物真正想要什么、为什么只能这样选、冲突由谁造成、代价如何结算、世界规则怎样迫使不同结果。不要只做同义词替换、打乱句序或表面换皮。修订涉及情节和追踪时交给 `story-long-write` / `story-short-write`。

## 与 oh-story-claudecode 配合

读取 `references/oh-story-integration.md`：

- 上游 scan/analyze 可提供市场样本和拆文产物；这些产物只能作为来源证据，不能直接复制进新稿。
- 上游 write 负责从独立故事核与项目设定创作；本 skill 在设计阶段记录来源，在成稿后审计距离。
- 上游 `story-review` 的综合质量审查不替代本 skill 的逐来源比较。
- 上游 `story-import` 只做项目结构化导入，不改变原稿的权利状态。

## 交付

输出：审计范围与盲区、来源清单、文字候选、场景/结构映射、COMMON 与独特贡献、风险分级、证据位置、修订目标、授权或署名待办、外部复核建议。不得把“未发现”写成“绝对不存在”。
