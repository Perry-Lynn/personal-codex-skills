# 读者反馈编码

先保留原评论、时间、对应章节和可见互动量，再做主题编码。

建议主题：

- `PROMISE`：题材或开篇承诺是否兑现。
- `CLARITY`：人物、行动、信息或时间是否难懂。
- `PACE`：拖、赶、重复、跳跃或断点。
- `CHARACTER`：人物动机、好感、行为一致性。
- `EMOTION`：爽、虐、甜、怕、感动等是否交付。
- `TRUST`：强行降智、视角作弊、吃设定或重复灌水。
- `FORMAT`：错字、排版、章节长度、更新问题。
- `NOISE`：刷屏、无关争论、仅表情或无法定位内容。

编码时区分“评论明确说了什么”和“我们推断它代表什么”。少量高赞评论可作为假设来源，不能直接等同于总体流失原因。
