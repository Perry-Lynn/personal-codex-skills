# 与 oh-story-claudecode 的互操作

本 skill 是个人互补扩展，不属于 `worldwonderer/oh-story-claudecode`。不要修改或冒充上游版本。

## 推荐链路

1. 用上游 `story-long-write` 或 `story-short-write` 产出正文。
2. 复制或锁定待审正文快照，运行本 skill 第一遍盲读。
3. 第一遍结束后，再读取上游项目的大纲、设定与追踪，完成第二遍对照。
4. 用上游 `story-review` 综合复核结构、逻辑、人物和连续性。
5. 需要改稿时，把“位置 + 读者误解 + 最小修订目标”交给对应写作 skill。

## 发现与降级

- 若 `$story` 路由已包含个人扩展，读者视角、盲读、弃读点等意图应路由到 `$story-reader-cold-read`。
- 若上游 skill 可用，引用其规范项目文件，不复制其写作与追踪规则。
- 若上游 skill 不可用，直接对用户提供的正文运行；第二遍没有作者资料时停在读者体验报告，不猜作者意图。
- 上游更新覆盖个人路由时，只恢复个人扩展路由项；不要改上游 skill 的实现文件或版本号。

## 数据交接

输入上游正文时保持原章节顺序和文件名。输出至少包含可定位的位置、第一遍读者理解、第二遍意图偏差和建议交接对象，供 `story-review` 或写作 skill 使用。
