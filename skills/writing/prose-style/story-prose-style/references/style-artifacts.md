# 项目文风产物模板

## 产物职责

- `设定/文风.md`：规范性文件，回答“必须怎么写、不能怎么写”。
- `设定/正文文风指纹.md`：描述性文件，回答“稳定样章实际上怎么写、哪些指标会漂移”。

两者冲突时，以用户本轮要求和 `文风.md` 为准。指纹不能反过来锁死题材节奏。

## 建立和更新规则

1. 使用用户认可、已定稿且能代表常态的样章；特殊高潮、实验章和旧稿不能单独定基准。
2. 初次建档可用 3–10 章；每完成 5–10 章或一次大规模回炉后重新校准。
3. 指标写区间和适用章节类型，不写单一硬比例。
4. 角色声纹记录思维与关系姿态，不只抄口头禅。
5. 新正文偶发偏离先记为样本差异；连续多章稳定变化并得到用户认可后才更新指纹。
6. 不因更新指纹修改历史正文；需要回炉时单独获得授权。
