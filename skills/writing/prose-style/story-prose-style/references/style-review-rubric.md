# 文风校准量表

## 分级

| 等级 | 含义 | 处置 |
|---|---|---|
| BREAK | 破坏项目核心文风契约或人物声音 | 修订后再交稿 |
| DRIFT | 连续、明显偏离稳定样本 | 给出证据并校准 |
| TUNE | 局部表达可优化，不影响整体声音 | 按用户授权处理 |
| PASS | 本次范围未发现明确漂移 | 不代表没有其他剧情问题 |

## 审查顺序

1. 确认受检文本属于哪个项目，读取文风权威文件和稳定样本。
2. 先检查事实、行动、信息和因果；逻辑错误不能包装成文风问题。
3. 比较对白、叙述、句段、描写、情绪、幽默和章尾。
4. 运行 `style_fingerprint.py`，把明显指标偏移当作检索入口，不直接当结论。
5. 检查AI模板、翻译腔、角色同声、流水账和空洞文学性。
6. 修订时先删无功能内容，再改写必要信息，最后复查人物和连续性。

## 核心检查

### 对白

- [ ] 蒙住角色名仍能凭关注点、称呼、句式和关系姿态区分人物。
- [ ] 普通交流不是连续短答、客服问答、设定讲解或段子接龙。
- [ ] 人物只说自己能知道、愿意说和当场需要说的信息。
- [ ] 笑点来自身份、误会、目的或处境，笑点后有动作或变化承接。

### 叙述

- [ ] 词语搭配自然，空间、动作和因果清楚。
- [ ] 文学性落在具体感官、物件、动作和后果，没有空景和抽象升华。
- [ ] 长短句按功能变化，没有电报体、逗号长拖或连续骈句。
- [ ] 心理主要由选择、动作和现场反应表现，没有精致反应流水线。

### 推进与题材

- [ ] 每个场景改变行动、信息、关系、风险或结果。
- [ ] 日常、调查、恐怖、战斗、感情和高潮使用相匹配的节奏。
- [ ] 爽点或情绪由压力、选择、行动、反应和结算形成。
- [ ] 章尾落到具体推动力，不做作者总结和预告升华。

### 模板风险

- [ ] 无高频“不是A而是B”、否定排比和标准答案式解释。
- [ ] 无成片“目光落在、嘴角勾起、微微、淡淡、仿佛”等套话。
- [ ] 无重复解释、工程元信息和替读者总结。
- [ ] 去AI味后没有删掉必要因果、角色动机、伏笔和场景载体。

## 报告模板

```markdown
# 文风校准报告

- 检查范围：
- 文风权威：
- 稳定样本：
- 总结论：BREAK / DRIFT / TUNE / PASS
- 指纹结果：

## BREAK
- 文件:行号｜原文摘要｜违反的项目规则｜建议修法

## DRIFT
- 文件:行号｜与样本的差异｜是否连续出现｜建议修法

## TUNE
- 文件:行号｜局部问题｜修改收益

## 保留项
- 哪些写法有角色辨识或题材功能，不应机械删除

## 修改与边界
- 已修改：
- 未修改：
- 是否影响连续性：
```
